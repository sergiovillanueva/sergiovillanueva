### Sergio Villanueva López

I build computer vision systems that inspect parts on automotive assembly lines. I am the technical lead of MEP,
a visual inspection product used by carmakers and Tier 1 suppliers, and I did an industrial PhD on anomaly
detection for visual inspection at the Universitat de València (2026).

**Research code.** Each repository goes with a journal paper. All of them use frozen foundation-model features and
need no training per product.

| Repository | What it does |
|---|---|
| [GaLAD](https://github.com/sergiovillanueva/GaLAD_Gaussian_layered_AD) | Sets up a new product from 1 to 5 good images and finds small defects |
| [pc-reg](https://github.com/sergiovillanueva/pc-reg) | Finds parts that are missing or in the wrong place |
| [memory-pollution-ad](https://github.com/sergiovillanueva/memory-pollution-ad) | One memory bank for many products, without interference between them |
| [patch-purification-fewshot](https://github.com/sergiovillanueva/patch-purification-fewshot) | Flags defective images in the reference set when a station is commissioned |
| [rgb-ensembles-industrial-uad](https://github.com/sergiovillanueva/rgb-ensembles-industrial-uad) | Detector ensembles on a real automotive benchmark |
